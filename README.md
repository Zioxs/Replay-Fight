# Replay Fight ⚔️📹

**Fix your Epic Fight animations in Replay Mod!**

Replay Fight is a simple patch that allows the **Epic Fight Mod** animations to render correctly within **Replay Mod**.

### Features
* **Animation Sync:** Fixes static or broken player models during replay playback.
* **Plug & Play:** Just drop it in your mods folder no configuration required.

### Requirements
1.  [Epic Fight](https://modrinth.com/mod/epic-fight)
2.  [ReForgedPlay](https://www.curseforge.com/minecraft/mc-mods/reforgedplay-mod) (Forge fork of Replay Mod)
3.  Replay Fight (This mod)
